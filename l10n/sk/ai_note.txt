Target language: Slovak. English name: Slovak. Endonym: "slovenčina" (also
"slovenský jazyk"), spoken in Slovakia.

THIS IS NOT SLOVENIAN. Slovenian is a separate language, locale code "sl",
endonym "slovenščina". Never answer in Slovenian, and never mix the two.

How to tell them apart:
- Slovak uses the letters ľ, ĺ, ŕ, ô, ť, ď, ň. Slovenian never uses them, and
  it has no letter that Slovak lacks among č, š, ž.
- Slovak declines with a genitive ("Nastavenia", "ponuka zvýraznenia").
  Slovenian uses a dative ("Nastavitve", "meni označb").
- Frequent confusions, Slovak first, Slovenian second:
    Copy        Kopírovať      / Kopiraj
    Update      Aktualizovať   / Posodobi
    Yes / No    Áno / Nie      / Da / Ne
    OK          OK             / V redu
    Settings    Nastavenia     / Nastavitve
    Remove      Odstrániť      / Odstrani
    Create      Vytvoriť       / Ustvari
    Device      Zariadenie     / Naprava
    Purge       Vyčistiť       / Počisti
    Translate   Preložiť       / Prevajdi
    Highlight   zvýraznenie    / označba
