Target language: Slovenian. English name: Slovenian. Endonym: "slovenščina",
spoken in Slovenia.

THIS IS NOT SLOVAK. Slovak is a separate language, locale code "sk", endonym
"slovenčina". Never answer in Slovak, and never mix the two.

How to tell them apart:
- Slovenian never uses the letters ľ, ĺ, ŕ, ô, ť, ď, ň. If a candidate
  translation needs them, it is Slovak, not Slovenian.
- Slovenian declines with a dative ("nastavitve", "meni označb").
  Slovak uses a genitive ("nastavenia", "ponuka zvýraznenia").
- Frequent confusions, Slovenian first, Slovak second:
    Copy        Kopiraj        / Kopírovať
    Update      Posodobi       / Aktualizovať
    Yes / No    Da / Ne        / Áno / Nie
    OK          V redu         / OK
    Settings    Nastavitve     / Nastavenia
    Remove      Odstrani       / Odstrániť
    Create      Ustvari        / Vytvoriť
    Device      Naprava        / Zariadenie
    Purge       Počisti        / Vyčistiť
    Translate   Prevajdi       / Preložiť
    Highlight   označba        / zvýraznenie
